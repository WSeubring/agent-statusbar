# pi integration

Files specific to pi.

## Files

- `extensions/status-footer.ts` — custom footer extension for pi

## Run

In this repo, pi auto-loads the compatibility shim in `.pi/extensions/pi-status-footer.ts`.

If you want to load the integration directly from elsewhere:

```bash
pi -e /absolute/path/to/integrations/pi/extensions/status-footer.ts
```
